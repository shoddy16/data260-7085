# Code Review Instructions

- Review the submitted code for correctness, clarity, maintainability, and compliance with the assignment requirements.
- Identify concrete problems rather than making vague comments.
- Explain why each identified problem matters.
- Suggest a specific improvement for each problem.
- Do not rewrite the entire code unless explicitly requested.
- Do not invent requirements that are not present in the assignment.
- Prioritize functional and requirement-related issues before style preferences.
- Verify claims against the supplied code and assignment requirements.
- Return the review using bullet points only.
- Do not use paragraphs outside bullet points.
- Do not use markdown tables.
- Do not include code fences.
