# HW9 metrics

Metrics are generated by `python -m data.hw9.experiments` and written to
`reports/hw09/raw/threshold_sweep.json`. The cost model is explicit in that
file: one unit for a cache miss and eight units for a false hit.

Offline deterministic sweep: threshold 0.75 cost 133, 0.80 cost 120, 0.85
cost 89, 0.90 cost 49, and 0.95 cost 30. At 0.95 the observed false-hit rate
was 0/40, with 10/40 exact-reference hits. These values are fallback-embedding
measurements, not live Ollama measurements.

Live embedding model: `nomic-embed-text`, 768 dimensions, numeric vectors;
direct cosine for the recorded paraphrase was 0.9385986732. The migrated
Redis HNSW index is `s7085:semantic_cache_idx_v768`, DIM=768, COSINE, with
zero current indexing failures after dropping the stale 64-dimensional index.

The live KNN validation uses the `embedding_vector` alias and Redis HNSW search
against that index. Redis returns cosine distance; the application converts it
to similarity before applying signature and data-version guards. The exact,
paraphrase, logical-difference, unrelated, stale-version, empty-index, and
concurrent-query results are recorded in `raw/live_knn_validation.json`.

Live sweep results (40 frozen cases, same cost model):

| Threshold | Hits | False hits | Hit rate | False-hit rate | Mean latency (ms) | Total cost |
|---:|---:|---:|---:|---:|---:|---:|
| 0.75 | 29 | 9 | 0.725 | 0.225 | 1251.3 | 83 |
| 0.80 | 28 | 8 | 0.700 | 0.200 | 41.4 | 76 |
| 0.85 | 27 | 8 | 0.675 | 0.200 | 56.6 | 77 |
| 0.90 | 22 | 6 | 0.550 | 0.150 | 52.4 | 66 |
| 0.95 | 13 | 3 | 0.325 | 0.075 | 59.5 | 51 |

For the table above, hit rate is cache hits / 40. False-hit rate for rubric
interpretation is false hits / 20, because 20 cases are labeled should-miss:
0.75=0.450, 0.80=0.400, 0.85=0.400, 0.90=0.300, and 0.95=0.150. The raw
JSON also retains false hits / 40 for comparison. Total cost is
`(40 - hits) * 1 + false_hits * 8`.

Qualifying post-commit sweep: commit
`a7533e7d5eb1df286b77450ce7999d0ad6a5a12d` contains only `cache_cases.yaml`.
`raw/threshold_sweep_qualifying_knn.json` records all five thresholds using live
`nomic-embed-text` embeddings and Redis KNN. Every result row reports
`redis_knn=true`, with 40 cases, 20 expected hits, and 20 expected misses.
The qualifying costs were 83, 76, 77, 66, and 51 for thresholds 0.75 through
0.95 respectively. The lowest measured cost is therefore 51 at 0.95, but the
signature and data-version safeguards remain necessary because false hits still
occurred at every threshold.

Live API cases recorded an exact duplicate as a hit with similarity 1.0 and
`agent_executed=false`, the paraphrase as a hit with similarity 0.9385986732,
and the above-70 logical variant and unrelated binary-search query as misses.
MySQL/Redis view validation recorded counts 1, 2, 10, 20, and 21, database
persistence at 20, and concurrent Redis/database counts of 20. The prior
1.5-second application embedding timeout was replaced with a 30-second
configurable timeout because the live local embedding call can take longer;
the timeout is `OLLAMA_EMBEDDING_TIMEOUT`.

Self-improvement latency is measured with `time.perf_counter()` around each
held-out question's answer/evaluation path and averaged over the same ten test
questions for every variant. It includes deterministic local answer/evaluator
work and lesson-file operations where applicable, but not Ollama network time;
the raw artifact stores the resulting aggregate averages.
